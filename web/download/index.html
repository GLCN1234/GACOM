    IF SOMETHING GOES WRONG

    It says "App not installed"

    You may already have an older GACOM on your phone that came from a different download. Uninstall the old GACOM (your account and progress are saved online), then install again. Also make sure you have at least 300 MB of free space.

    It says "Parse error" or "App not compatible"

    The file does not match your phone. Use the "Download the other version" button above, or the standard version if you tried the small one.

    Play Protect shows a warning

    GACOM is not on Google Play, so Android shows a general caution for apps from outside the store. Tap More details, then Install anyway. If you see "Scan app", you can scan it first and then install.

    The download is stuck or keeps failing

    Use Chrome on Wi-Fi if you can, turn off any data saver, and try again. The download continues where it stopped if the connection drops.

    The phone will not let me open the file

    Open your Files or My Files app, go to Downloads, and tap the GACOM file there.
